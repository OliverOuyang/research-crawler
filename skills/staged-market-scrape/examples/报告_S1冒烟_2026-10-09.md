## 3. 初步发现（只作为下一阶段的假设）
- 手写笔记 App 的讨论集中在 Goodnotes、Notability、Notewise、Freenotes，Obsidian 是另一类人群（推断：知识管理类和手写类是两个市场，要分开抓）。
- 痛点信号：渲染/卡顿、手写自动平滑、订阅涨价（Notability 改月订阅），以及“找更便宜的 Goodnotes 替代品”。
- TikTok 视频的收藏数中位数约为点赞数的 33%，说明“教程/推荐”类内容被大量收藏（推断：用户在做选择前会收藏比较）。
- Trends：过去 12 个月相对值在 44–100 之间，**峰值在 2026-08-23 那一周（开学季）**，1 月也有一波（新学期），7 月最低。季节性明显。

## 4. 如何使用这批数据

**字段说明：**
- Reddit：`score`=抓取时的点赞净值，`num_comments`=帖子评论总数（只对帖子有），`created_utc`=发布时间，`retrieved_at`=抓取时间，`is_deleted_or_removed`=作者注销或内容被删
- TikTok 视频：`views`、`likes`、`comments`、`shares`、`bookmarks`、`uploadedAtFormatted`
- TikTok 评论：`diggCount`=评论点赞，`replyCommentTotal`=回复数，`createTimeISO`
- Trends：`timeline_data["note taking app"]`=周值（0–100 相对值），`timeline_data.isPartial`=该周是否未完结

**适合做什么：** 收集痛点原话、统计竞品被提及的次数、看需求的季节性。
**不适合做什么：** 估算市场规模；把 TikTok 播放量当购买意愿；拿这条 Trends 曲线和另一次请求的数值比较。

**加载示例：**
```python
import json
d = "/mnt/project-files/research/apify实测样本/"
reddit = [x for x in json.load(open(d + "reddit_tavily_urls.json")) if not x["is_deleted_or_removed"]]
trend = json.load(open(d + "trends_note_taking_app_US_12m.json"))[0]["timeline_data"]
weekly = {k: v for k, v in trend["note taking app"].items() if not trend["isPartial"][k]}
```
