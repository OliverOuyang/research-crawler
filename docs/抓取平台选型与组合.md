# Tavily + 抓取平台：选型、价格与推荐组合

> 调研时间：2026-10-09。Apify 抓取器数据来自 Apify Store 公开 API（未登录、未运行任何 Actor）；其他平台价格来自各家官网和 2026 年的第三方对比文章，正式付费前以官网为准。
> “成功率”= 该 Actor 近 30 天公开运行中 SUCCEEDED 的比例。Apify 价格按 Free 档计，付费档更便宜。

## 一、结论

1. **Tavily 和 Apify 分工明确，可以组合用。** Tavily 负责“找”（用关键词发现相关 Reddit 帖子、行业文章、竞品页面），Apify 负责“抓结构化数据”（点赞数、评论数、精确时间、TikTok 视频和评论、Trends 曲线）。Tavily 补不上的三个缺口，Apify 上都有成熟的抓取器。
2. **Apify 本身已经不贵**，因为热门 Reddit/TikTok/Trends 抓取器都是按条计费（$0.3–4 / 千条），不按算力。一轮调研（见第四节估算）大约 $3–15，Free 档每月 $5 额度能跑一轮小样本，Starter $19/月足够常规用。
3. **真正更便宜的平替只有局部的：** Google Trends 用 SerpApi 每月 250 次免费，TikTok 用 Bright Data 每月 5,000 条免费。没有哪一家能在三个数据源上同时比 Apify 便宜又稳。
4. **推荐：Tavily（已有）+ Apify Free/Starter 为主，Trends 可备选 SerpApi 免费档做交叉验证。** Reddit 量化数据仍优先走官方 OAuth API（免费、合规），Apify 作为补充。

## 四、一轮调研的成本估算

假设：Reddit 400 帖 + 4,000 评论；TikTok 300 视频 + 3,000 评论；Trends 50 个关键词。

| 方案 | Reddit | TikTok | Trends | 合计 |
|---|---|---|---|---|
| Apify 最省（automation-lab + apidojo + data_xplorer） | ≈ $2.8 | ≈ $1.0 | ≈ $0.1 | **≈ $4**（Free 档够） |
| Apify 最稳（fatihtahta + clockworks + data_xplorer） | ≈ $6.6 | ≈ $4.9 | ≈ $0.1 | **≈ $12**（Starter 档） |
| 平替混搭（Reddit 官方 API + Bright Data 免费档 + SerpApi 免费档） | $0 | $0（5k 条内） | $0（250 次内） | **$0**，但要维护三套接入 |

## 五、推荐的分工

| 环节 | 用什么 |
|---|---|
| 发现话题、找相关帖子和文章 | Tavily /search |
| Reddit 帖子正文快速定性 | Tavily /extract（已实测可用） |
| Reddit 量化（点赞、评论数、时间） | 首选官方 OAuth API；备选 Apify fatihtahta 或 automation-lab |
| TikTok 视频和评论 | Apify：先 clockworks（稳）或 apidojo（便宜）抓视频，再串评论抓取器 |
| Google Trends 曲线 | Apify data_xplorer；SerpApi 免费档做交叉验证 |

## 六、质量与合规提醒（对照《爬取实测与数据原则》）

- Apify 抓到的点赞/评论数是**抓取那一刻的值**，仍要遵守质量标准 B：帖子发布 ≥ 72 小时后再抓才用指标。
- 第三方抓取器都会报“成功”，但仍要按标准 A 校验条数和关键字段；首次使用每个 Actor 先跑 20–50 条小样本人工核对。
- 这些平台是代抓公开页面，Reddit 和 TikTok 的使用条款不因此改变。调研阶段内部分析可以，数据进产品或对外售卖前要先拿授权（原则第 2 条）。
- 不要把 TikTok 播放量当购买意愿，不要拼接多次 Trends 请求的数值（原则第 12、13 条）。

## 七、要实测需要做的事

1. 在 apify.com 注册（免费，无需信用卡），在 Console → Settings → API & Integrations 复制 API token。
2. 在项目云环境里加一个 Network secret：域名 `api.apify.com`，以 `Authorization: Bearer <token>` 注入（和 Tavily 的做法一样）。不要把 token 贴到聊天里。
3. 新开的会话会生效。之后可以按第四节的小样本跑一轮，用质量标准逐项验收。
